This project is an offline-first flashcards PWA.

Tech stack:
- React + TypeScript
- Vite
- Material UI (MUI)
- IndexedDB (Dexie)
- Zustand for state
- Strict TypeScript

Architecture rules:
- No any types
- Functional components only
- Feature-based folder structure
- Separate DB layer
- Separate training engine logic
- Mobile-first design
- Must work offline

Never generate mock APIs or server logic.
Everything is local-first.
